# 이용 가능한 실내 공간 제작

스케일은 real-world-scale 스킬 기준(1m = 3 studs)을 따른다.

## 초등학교
- **교실**: 2인용 책상을 행/열 배치(실제 초등 교실은 보통 4~5열), 교탁, 칠판, 뒤쪽 사물함/게시판, 창문 위치는 로드뷰/실제 구조 참조.
- **복도**: 폭 2.5~3m(7.5~9 studs), 신발장, 창가 난간.
- **체육관**: 바닥-천장 8m+, 농구 골대(골대 높이 2.55m 초등용 규격 확인), 스탠드, 줄담기 등 기자재.

## 상점 (편의점/문구점/분식점)
- 편의점: 진열대 동선(실제 편의점 배치 참조), 계산대, 냉동고, ATM 위치.
- 문구점: 진열대 밀도 높게, 필통/노트 표현은 Decal로 절약.
- 분식점: 주방/좌석 구분, 메뉴판은 SurfaceGui.
- 상호작용(물건 집기, 계산)은 RemoteEvent + 서버 검증 패턴으로. 모든 재고/돈 로직은 서버에서.

## 아파트 + 엘리베이터
- **엘리베이터**: 서버 Script로 구현. 로비/각 층에 호출 버튼, 실내에 층 버튼 UI. 문 닫힘 → 이동(캐릭터를 실제로 태우고 이동하거나 로딩 순간 텔레포트) → 문 열림. 카메라 흔들림 없이 부드럽게.
- **세대 내부**: 현관, 거실, 주방, 방, 욕실 기본 배치. 실제 특정 세대를 재현하지 않고 전형적인 평면도 기반으로 제작한다.
- 층별 배치는 같은 평면형을 템플릿화해 복제.

## 성능
- 실내는 스트리밍 영역(보이지 않을 때 로드 억제)으로 관리한다. city-map-organization 스킬 참조.
- 실내 가구 중 상호작용 없는 것은 Union 또는 단일 MeshPart로 통합한다.

## 노하우 축적
- 실내 제작 패턴, 엘리베이터 구현 개선점 등을 이 스킬에 계속 기록한다.
