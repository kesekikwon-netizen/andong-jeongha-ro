# 실측 스케일 표준 (안동 리얼리티 맵 프로젝트)

## 프로젝트 표준 비율 (Roblox 공식 기준)
- **1 stud = 0.28m → 1m = 3.571428 studs (≈ 3.57)**
- 과거의 "1m = 3 studs" 규칙은 폐기. 모든 실측 미터 값은 × 3.5714로 변환한다.
- 주의: 기본 캐릭터(약 5 studs)는 공식 환산 기준 약 1.4m로, 실제 성인(170cm)보다 작다. 실제 비율을 맞추려면 캐릭터 전체 스케일을 약 1.22배(키 약 6.07 studs)로 조정한다. 프로젝트 전체에서 반드시 한 가지 기준만 일관되게 사용한다.

## 자주 쓰는 변환표 (1m = 3.5714 studs)
- 성인 키 170cm → 6.07 studs
- 차선 1개 폭 3.5m → 12.5 studs
- 2차선 도로(이면도로) 7~8m → 25~28.6 studs
- 인도 폭 1.5~2m → 5.4~7.1 studs
- 건물 1층 층고 3~4m → 10.7~14.3 studs (1층 상가 특성상 높게)
- 아파트 층고 2.7m → 9.6 studs
- 문 높이 2.1~2.4m → 7.5~8.6 studs
- 승용차 4.8m×1.8m → 17.1×6.4 studs
- 초등학교 교실 대략 8m×7m → 28.6×25 studs (로드뷰/실측 확인 후 확정)
- 체육관 바닥-천장 높이 8m 이상 → 28.6+ studs

## 검증 워크플로
1. 로드뷰/실측에서 사람(170cm), 승용차(4.8m), 문(2.1m)을 기준으로 실제 크기를 추정한다.
2. Studio에서 캐릭터를 해당 위치에 세워 나란히 비교한다.
3. studio_execute_luau로 두 지점 간 거리, 파트 GetBoundingBox 크기를 측정해 변환표에 기록한다.
4. 기존 Roblox 기본 에셋(문, 계단, 가구)은 실측 비율과 안 맞는 경우가 많으니 반드시 직접 제작하거나 크기를 보정한다.

## 주의
- 스케일 감수성이 흐려지면 강남초 운동장(실측 크기 확인)을 기준 리셋 지점으로 삼아 주기적으로 재검증한다.
- 새로 측정한 실측값이 생기면 이 스킬의 변환표에 추가해 노하우로 축적한다.
