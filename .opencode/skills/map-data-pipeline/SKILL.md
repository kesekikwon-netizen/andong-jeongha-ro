# 실측 지도 데이터 파이프라인 (VWorld + 로드뷰)

## 지오레퍼런싱 규칙
1. **기준점**: 강남초등학교 운동장 중앙을 Studio 좌표 (0, 0)으로 설정한다.
2. **방향**: 실제 북쪽을 Studio -Z축으로 고정한다. 모든 지도 데이터를 이 규칙에 맞춰 배치한다.
3. **축척**: 실제 1m = 3 studs (real-world-scale 스킬 참조).
4. 기준점에서 실제 좌표(위경도)를 기록해 두면, 향후 안동시 어느 지역이든 상대 좌표로 배치할 수 있다.

## 워크플로
1. **수집**: VWorld API로 대상 구역의 항공/직교 영상 타일을 받는다. API 키는 절대 스크립트에 하드코딩하지 않는다.
2. **기준 평면**: Studio의 잠긴 "Reference" 폴더에 대형 평면 파트를 만들고 영상을 텍스처로 부착한다. Y를 지면보다 낮게(예: -50) 두고 Transparency로 겹치지 않게 관리한다. 이 기준 평면 위에서 위성사진을 보며 도로/필지/건물 외곽선을 추적한다.
3. **추적**: 도로 → 필지 경계 → 건물 footprint 순서로 파트로 외곽선을 잡는다. 높이는 로드뷰에서 층수를 세어 층고×층수로 계산한다.
4. **디테일 보강**: footprint 위에서 네이버 로드뷰를 하나하나 열어 각 건물의 외관, 간판, 1층 상가 구성을 확인하고 기록한다.
5. **게시 전 정리**: Reference 폴더와 원본 영상 텍스처는 배포 전 반드시 제거하거나 교체한다.

## 영상 등록
- 로컬 이미지는 studio_store_image으로, 업로드는 studio_upload_image으로 assetId를 받아 텍스처/Decal로 쓴다.

## 법적 주의
- VWorld 및 네이버 로드뷰 데이터의 이용약관과 저작권 범위를 확인하고, 허용 범위 내에서 참조용으로 사용한다. 실제 간판 디자인을 그대로 복제할 때는 상표/저작권 문제가 없는지 판단하고, 애매하면 유사한 가상 간판으로 대체한다.

## 노하우 축적
- 새로 익힌 VWorld API 사용법, 타일 좌표 계산법, 영상 해상도별 권장 사용처 등을 이 스킬에 계속 추가한다.
