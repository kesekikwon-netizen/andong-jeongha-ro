# 상시 지침 (Standing Orders)

발효: 2026-10-23. 사용자가 직접 폐기하기 전까지 모든 작업에 적용된다.

1. **최대 병렬 개발이 기본이다.** 서로 겹치지 않는 작업은 항상 병렬 서브에이전트로 나눈다.
   새 파일 단위로 분할하고, 단일 진실 공급원(Builder 배선, Blocks 병합)은 메인만 만진다.
2. **모든 작업은 Studio에 실시간으로 보인다.** Rojo serve 유지 + `execute_luau`로
   Edit 모드 빌드 + `screen_capture`로 확인. 말로만 "됐다"고 하지 않는다.
3. **밑그림은 위성, 수정은 로드뷰, 장면 단위 스캔.** waypoint 하나씩 캡처→채점→수정→재촬영.
   한 장면이 끝나야 다음 장면으로 간다. 회귀(기존 점수 하락) 0건을 gate로 한다.
4. **스킬은 개발과 함께 추가·진화한다.** 같은 실수가 2회 반복되면 스킬 체크리스트로 승격,
   성공 패턴은 예시로 추가. 스킬 변경 후 waypoint 점수가 떨어지면 롤백.
5. **종료 조건:** 전 waypoint 95% + 랜드마크 100% + 회귀 0건. 그 전까지 루프는 멈추지 않는다.
6. **좌표계:** 원점=학교 정문 중앙, +X=동, +Z=남, 단위 미터. 파트 생성은 Geometry 모듈만 사용.
7. **로드뷰 이미지를 텍스처로 굽지 않는다.** 보면서 형상·비율·색을 관찰해 모델링만 한다.
   간판은 텍스트로만 표기하고 로고 이미지는 사용하지 않는다.
8. **데이터 상태 정직 표기:** `verified=false`는 추정치라는 뜻. 확인된 것만 true로 바꾼다.
9. **VWorld 키 상태 (2026-10-23):** 제공된 키는 Data API에서 `INCORRECT_KEY`로 거부됨.
   vworld.kr 마이페이지에서 DATA API 사용 설정 + 키 재확인 필요. 해결 전까지 위성 수동 트레이싱.
10. **Roblox skill + MCP 적극 사용 (상시 명령):** Studio 내장 `rbx-*` 스킬과 MCP 도구
    (`roblox_studio` 28종 + `conduit` 20종)를 매 작업에 우선 사용한다. 필요한 스킬·도구가
    없으면 새로 추가해서 사용하고, 그 과정을 스킬 파일로 기록한다.
11. **전부 만든 뒤 사용자 검토, 무한루프 (상시 명령):** 한 사이클 분량을 다 만들면
    사용자 검토를 받고, 수정→확인→개발 루프를 무한 반복한다. 검토 없이 다음 사이클로
    넘어가지 않는다. (기록일: 2026-10-23, 사용자 직접 지시)
12. **시각 품질 바 (2026-10-24 확정):** 스타일라이즈드 트윈 (파라메트릭 박스 모델링 유지하되
    실측 좌표·회전각 `+6.5°`·층수·색상·양면 간판·도로 표지·조경·캐노피 디테일로 한눈에 알아볼 수 있는 수준).

기준 좌표: 안동강남초등학교 36.549777, 128.731262 (동측 정문: X=+104.8m, Z=+4.7m, 강남1길 본선: X=+114.9m).
